# Playbook

这些 playbook 是为本选集编写的应用。它们将 Ryan Lopopolo 的公共写作和其他有记录的证据中发展出的论点和案例，安排成人类和 agent 可以尝试的过程。两份文件都不是 Ryan 发布的源文本或 playbook。

| 工作 | Playbook |
| --- | --- |
| 改善一个有界、代表性工作周围的 harness | [Improve One Harnessed Job] |
| 审查跨仓库的多个旅程和所有权边界 | [Repository Review] |
| 比较条件或随时间衡量变化 | [Evaluate the Harness] |

[Improve One Harnessed Job]: improve-harness.md
[Repository Review]: repository-review.md
[Evaluate the Harness]: ../evals/

前两个过程是编辑综合；本仓库尚未包含其中任何一个的端到端应用记录。在目标自己的 instructions 和 authority 下使用它们，并记录发生的情况。在使用中发现的错误或遗漏进行报告；仅在针对此仓库的单独授权任务中修改 playbook。
